# LE-Cohart_project
🩺 AI-Based Medical Chatbot

📌 Project Overview

The AI-Based Medical Chatbot is a Python project designed to answer users' health-related questions using artificial intelligence and information retrieval.

🎯 Objectives

- Provide clear responses to health-related questions.
- Retrieve relevant information from a knowledge database.
- Use Google's Gemini AI model to rephrase retrieved information into easy-to-understand answers.

⚙️ Technologies Used

- Python — Programming language
- Google Gemini API — Generates conversational responses
- Semantic Retrieval — Finds relevant information from stored data
- Jupyter Notebook / Google Colab — Development environment

✨ Key Features

- Answers health-related questions.
- Retrieves relevant information before generating a response.
- Uses retrieved information as the source for its answers.
- Provides user-friendly conversational responses.

🚀 How to Run

1. Download or clone this repository.
2. Open "Medical_chatbot (2).ipynb" in Google Colab or Jupyter Notebook.
3. Install the required Python libraries.
4. Configure your Gemini API key securely.
5. Run the notebook cells in order and test the chatbot.

⚠️ Disclaimer

This chatbot is for educational and informational purposes only. It does not replace professional medical advice, diagnosis, or treatment.
